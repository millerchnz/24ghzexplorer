Privacy policy

2.4 GHz Explorer · Android package com.millerchnz.ghzexplorer

Effective 18 October 2026

2.4 GHz Explorer reads the Wi-Fi, Bluetooth, NFC, and cellular APIs on this phone and shows the values they return. This policy describes what the app stores and when anything leaves the phone.

Data stored on the device

The app stores the following in app-private storage on your device:

  • The latest pairing events aimed at this phone: time, device name, address, bond or connection change, the pairing variant, and any numeric key Android included in that broadcast. The newest 40 events are kept.
  • A flag that the in-app help tour has been finished.
  • Map tiles cached so the Find device and list maps can draw the street map again.
  • Text files created when you tap Export, kept in the app cache until you share them or the system clears the cache.

Wi-Fi, Bluetooth, NFC, and cell readings are held in memory while the app is running. They are not written to storage. A Wi-Fi password typed into Connect is passed to Android’s system prompt and is not stored or logged by this app. Location samples used to plot a walk stay in memory for that screen and are dropped when you leave it.

Pairing events and the tour flag are excluded from Android backup and from device-to-device transfer. The developer does not operate a server for this app and does not receive this data.

When data leaves the device

  • Map tiles. The Find device and list maps load OpenStreetMap tiles over HTTPS from the OpenStreetMap tile servers so they can draw the area on screen. A tile request includes the coordinates of that map view.
  • Export. If you export or share a text file, that file goes to the app you choose. It contains the device fields on screen, and the first and last place this phone heard the device when those places were recorded, with the signal strength there.

Accounts, ads, and analytics

The app has no user accounts. It does not show ads, and it does not include an analytics or crash-reporting SDK.

Deleting your data

Uninstalling the app deletes everything it stored, including pairing events, the tour flag, cached map tiles, and export files. The developer has no copy of that data. A file you already shared is held by the app you sent it to.

Children

2.4 GHz Explorer is a radio inspection tool aimed at people aged 18 and over. It is not directed at children.

Changes

If this policy changes, the updated page will replace this one and the effective date above will change. Continued use of the app after the new date means you accept the updated policy.
